# 工程长期路线

- 日期：2026-10-05
- 目标：从可演示模块化单体演进为可持续运行的电商智能运营与商品内容平台
- 原则：先治理和边界，再纵向切片；不一次性重写，不因短期展示扩大高风险范围

## 阶段总览

| 阶段 | 目标 | 主要交付 | 进入条件 | 完成门禁 |
|---|---|---|---|---|
| P0 基线治理 | 让工作区和事实可管理 | 文件清单、架构/领域文档、测试/迁移/发布证据 | 当前改动已保存 | 未跟踪运行依赖明确，事实/目标/未知分开 |
| P1 模块边界 | 降低入口和领域耦合 | Router、Application Service、DTO、错误和 context | P0 文档审查通过 | 行为不变、全量回归、跨租户负向通过 |
| P2 外部事实生产化 | 建立可持续平台同步 | Connector、授权引用、source batch、质量、回放、补偿 | 至少一个平台测试授权 | 只读 Canary 可停、可回放、可审计 |
| P3 OMS 订单只读 | 统一渠道订单和履约 proposal | UnifiedOrder、物流/轨迹事实、异常收件箱、审单/分仓草稿 | P2 外部事实稳定 | 外部订单与内部履约分离，物流回放、权限通过 |

| P12 受控开放 | 真实多租户和写能力 | OAuth、更多平台、独立审批写工具、Webhook/发布 | P2-P11 证据齐全 | 最小权限、人工审批、幂等、审计、补偿 |

## 第一轮：P0 基线治理

### 工作项

1. 保留当前工作区，不执行 reset/clean/delete/force overwrite。
2. 把未跟踪文件分类为运行时闭包、测试/fixture、技术文档、实验、个人资料和恢复文件。
3. 维护 `docs/product-architecture.md`、`docs/domain-boundaries.md` 和本路线。
4. 生成路由、模型、服务、导入依赖和测试映射清单。
5. 用 P0-0/P0-1 实测结果作为基线，不重复使用历史测试数字。
6. 记录 Alembic head、迁移重复升级、legacy 初始化、MySQL/offline SQL 未知项。

### DoD

- 核心运行时依赖闭包已确认；
- 个人资料和恢复文件不自动进入发布候选；
- 全量测试、定向测试和迁移证据有日期/命令/环境；
- 当前能力分为已验证、模拟、过渡、待授权和未知；
- 下一轮开发有明确领域和回滚方式。

## 第二轮：P1 模块边界

优先抽取不改变业务行为的只读分析/同步边界：

- `app/main.py` 只保留路由、鉴权、参数和响应；
- 分析查询进入 `AnalyticsQueryService`；
- 同步编排进入 `SyncApplicationService`；
- 内容流程进入 `ContentApplicationService`；
- 领域函数和 Repository 不依赖 FastAPI；
- 公共 `RequestContext` 传递 workspace、actor、request_id、source_mode；
- 统一 `DomainError` 到 HTTP 错误码的映射。

不在此轮搬迁所有模型文件；先用适配层和 contract tests 降低风险。

## 纵向切片要求

每条纵向切片必须包含：

```text
事实来源
→ 输入/输出契约
→ 权限范围
→ 状态机
→ 幂等/版本/事务
→ 外部调用与重试
→ 审计和 request ID
→ 正/负/越权/重复/故障测试
→ 指标和数据完整度
→ Runbook、回滚、人工接管
```

## 变更排序原则

优先级由以下因素共同决定：

```text
业务价值 × 风险降低 × 可验证性 × 可复用性 ÷ 交付成本
```

高影响写操作、真实平台接入和真实 LLM 不因“看起来完整”提前；先完成只读、proposal-only、回放和人工门禁。

## 风险登记

| 风险 | 当前状态 | 应对 |
|---|---|---|
| 工作区未跟踪运行代码 | 真实风险 | 发布闭包审查，不自动提交/删除 |
| 巨型 `main.py`/`db.py` | 架构债务 | P1 先抽应用服务和 Router，保持表兼容 |
| 单进程后台任务 | 本地过渡 | 先统一 Job Port，再用容量证据决定队列 |
| Hash/JSON/Stub RAG | 仅 demo | Provider/Index 抽象、评测、真实实现逐步替换 |
| 固定 MCP workspace | 安全风险 | 服务端可信 context，工具级 scope 测试 |
| 平台凭证 `.env` | Canary 限制 | secret_ref、授权生命周期和停用 |
| 采购到入库缺关联 | 指标/审计缺口 | 增加明确关联模型后再计算耗时 |
| AIGC 过渡 Provider | 质量未知 | 品类模板、真实商品验收和 QA/人工审核 |
| 指标口径漂移 | 持续风险 | metrics contract、版本、分母、完整度 |

## 停止条件

出现以下任一情况，停止扩展功能，回到治理：

- 全量回归失败或关键权限测试失败；
- 外部观察值写入内部库存账本；
- 重放产生重复订单、库存流水、内容导出或通知；
- 无法证明数据来源、权限、版本或人工审批；
- 真实 Provider/平台授权和停止开关不明确；
- 指标缺分母或把 unknown/partial 当成功；
- 迁移无法在临时数据库升级、重复执行或恢复；
- 关键任务无法取消、恢复、死信或人工重放。
